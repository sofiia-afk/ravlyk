# Равлик — кабінет КПТ

Встановлюваний веб-застосунок (PWA) для КПТ-консультанта: картки клієнтів, формулювання за моделлю «Равлик»,
підтримуючі цикли, сесії, моніторинг шкал і бланк супервізії.

Цей репозиторій містить лише код застосунку. Записи клієнтів сюди не потрапляють: вони зберігаються
тільки на пристрої користувача і зашифровані паролем (PBKDF2-SHA256 + AES-GCM 256).

Встановлення на iPhone / iPad: відкрийте адресу сайту в Safari → «Поділитися» → «На початковий екран».
